Rätselwelt V3
==============

Inhalt:
- index.html  -> Hauptdatei der Rätsel-App
- logo.svg    -> Vollständiges Logo
- README.txt  -> Kurzinfo

Start:
- index.html im Browser öffnen
- empfohlen auf Tablet/iPad im Quer- oder Hochformat

Funktionen:
- 8 Rätselarten
- 4 Themenwelten
- 3 Schwierigkeitsstufen
- lokale Sternesammlung
- offline nutzbar

Hinweis:
- Alles läuft ohne Server direkt lokal im Browser.
